# Twice Around The Stream
`infosecctf`, `cryptography`

## Problem Statement
An engineer was tasked with securing a lightweight chat service. To keep things fast, the system encrypts messages using AES in CTR mode.

During development, messages were passed through a closed transformation in english before encryption. Later changes focused on performance, reusing certain encryption parameters across messages.

You managed to capture several encrypted messages from the service, all encoded for transport. One of them hides something important.

Can you recover it?
